What these guides cover

Generating a QR code takes about ten seconds. Getting one to work reliably in a real environment, a dim restaurant at 9pm, a printed card handled by a hundred people, a guest arriving with no data allowance, takes a handful of specifics that are rarely written down properly.

These guides cover that gap. Each one deals with a concrete situation rather than QR codes in general, and gives the numbers where numbers matter: minimum print sizes, the character counts where codes start failing, which test actually proves a WiFi code works, and where an ad or a code must not be placed.

Start here by situation

  • Running a rental property: begin with WiFi codes for Airbnb, which covers guest networks and printing.
  • Running a café or restaurant: which four codes are worth printing and where each belongs.
  • Running a hotel: guest WiFi, digital directory and accessibility.
  • Something is not working: the seven real causes, in diagnostic order.
  • About to send something to print: sizing, contrast and quiet zones.
  • Choosing a provider: static versus dynamic, and the dependency risk nobody mentions.
  • Worried about safety: how QR scams actually work and the one habit that prevents them.
