QR Code for a Word Document

A QR code cannot carry a Word file. It carries the address of one. Here is how to make it, when a PDF is the better thing to link to, and what we checked.

The short answer

The code holds a link, not the document

Upload the document to a place with a public web address, then make a QR code of that address. Scanning the code opens the link. The document stays where you put it.

Think about what the reader will do with it

If people only need to read the document, a PDF is usually the better thing to link to. If they need to edit it, link to the Word file or to a shared online copy. The rest of this guide covers both.

Why a Word file does not fit

We measured a blank document

The largest QR code holds 2,953 bytes at the lowest error correction level and 2,331 bytes at the medium level. We saved three .docx files made with the Python library python-docx and checked their sizes in bytes.

FileSize in bytesFull codes needed at the lowest level
Blank document36,56313
One page of text36,74713
Ten pages of text37,11913

What that tells you

A .docx file is a zipped bundle of files, so even a blank one has a large fixed part. Files made in Word itself, or with pictures and tables, will have different sizes. The point holds either way: it takes about a dozen full codes to carry a document with nothing in it, and no phone camera reads that. So the code must hold a link.

How to make a QR code for a Word document

Step 1: Put the file online

Use your own website, or a file sharing service. Set sharing so that anyone with the link can open the file. If a reader has to sign in or ask for access, they will see a login page instead of your document.

Step 2: Copy the link

For a file on your own site, the link ends in .docx or .doc. For a shared online copy, copy the share link. Our guide to QR codes for Google Drive covers Drive links in detail.

Step 3: Generate the code

Open the file and media QR code generator, paste the link and download the code. For a .docx link, the tool said: "Recognised a Word document. Most phones download a Word file rather than displaying it. If it only needs reading, export to PDF first."

Step 4: Test it

Scan the code with a phone that is not signed in to your account, and open the result. Then print a test copy at its real size. See QR code size for print for the minimum width.

Word file or PDF?

When a PDF is better

A PDF is meant to be read. Our file tool says that PDFs open in the phone's built in viewer, which is fine for a page or two, while Word files are more likely to be downloaded than shown. You can save a PDF from Word with the export or save as option, then use our PDF QR code generator.

When to keep the Word file

Keep it as a Word file when the reader must fill it in or edit it, such as a form or a template. In that case, tell people what to expect on the printed sign, for example "Scan to download the form".

Code size

Links of 28 to 39 characters all gave a 29 by 29 grid at the medium error correction level. At 0.4 mm per square plus a margin of 8 squares on each side, that needs at least 14.8 mm of width. These figures come from calculation with a QR library, not from printing. We did not test how each phone opens a Word file, so try yours.

Mistakes to avoid

A link that needs a sign in

Sharing links from work or school accounts are sometimes limited to people inside the organisation. Open the link in a private window before you print anything.

Linking to a file you will replace

A static code cannot change. If the link points to a file on your own site, you can replace the file and keep the same address. See static vs dynamic QR codes.

A very long link

Long links make denser codes that need printing larger. Keep the address short, and read how link length changes the size you need.

Frequently asked questions

Can a QR code store a Word document?

No. The biggest code holds 2,953 bytes, and a blank .docx we made was 36,563 bytes.

How do I turn a Word document into a QR code?

Put the file online, copy its public link, and paste the link into a QR code generator.

Should I use a PDF instead?

If people only need to read it, yes. If they need to edit or fill it in, keep the Word file.

Will the document download or open?

Our tool warns that many phones download Word files instead of showing them. We did not test every phone.

Does the QR code expire?

A static code does not expire by itself. It works for as long as the file stays at that link.

Can I change the document later?

Yes, if the link points to a file you control and you replace the file at the same address. Otherwise you must make a new code.
