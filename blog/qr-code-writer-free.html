The short answer

A QR code writer is a QR code generator

People search for a "QR code writer" when they want to make a QR code. The words writer, generator, maker and creator all mean the same tool: you type in some information, and it draws the code. There is no difference in what comes out.

What "write" really means

A QR code is drawn, not written to. It is a printed pattern that holds a piece of text, and once it is printed that text cannot be rewritten. That is why the writing step matters: you want the text right before it goes on paper.

The three steps

  1. Choose what the code should do.
  2. Write the details it should hold.
  3. Download it and test it.

Pick the type that matches the job

Every type of code holds text, but each follows its own format, so the phone knows what to do with it. A link opens a page, a WiFi code joins a network, a contact card offers to save a person. Pick the generator that matches the job.

Step 2: Write what goes inside

Type the details into the form

Each generator asks only for what its type needs. A WiFi code wants a network name and a password. A text message wants a number and a message. You type them in and press Generate, and the code appears straight away. It is built in your browser, so nothing you type is uploaded.

Step 3: Download it and test it

Download the right file

Download a PNG for screens, email and documents. If the code is going to a printer, use an SVG, which has no pixels and stays sharp at any size. Our custom QR code generator exports SVG and lets you change colours, with a check that the styled code still reads.

Three tests before you print

  1. Read it back. Open the code in our QR scanner. It shows the text inside, so you can spot a typo before it reaches paper.
  2. Scan it on a phone and check it does what you meant. For a link, open it in a private window to be sure it works for someone who is not signed in.
  3. Print one proof, at the real size, and scan that. A code that is too small or low contrast fails on paper even when it works on screen.

For the size to print, our guide to QR code size for print has the numbers, and why QR codes fail to scan covers what goes wrong.

What free means here

What you get

  • No account and no signup.
  • No watermark on the code.
  • Static codes, which cannot expire, because the text is inside the code and nothing sits behind it.

What you do not get

You cannot edit a printed code, and we do not count scans. Those features need a dynamic code, where a company's server sits between the scan and your page. Our guide to static vs dynamic QR codes explains the tradeoff, and why a static code is the safer choice for anything you print in quantity.

Frequently asked questions

Is a QR code writer different from a QR code generator?

No. They are two names for the same tool. Both turn the details you type into a QR code.

Can I write any QR code for free?

You can write any of the types listed above, and anything you can express as text, for free on this site. We do not offer dynamic codes, which need a server behind them.

How long does it take to write a QR code?

About three minutes, including the test. The code itself appears the moment you press Generate.

Can I change a QR code after I have written it?

Not a static one. The text is fixed inside the pattern. If you need to change the destination later, point the code at a page on a domain you own and update the page.

Does a QR code I write expire?

A static code does not. It is a printed pattern holding text, with no account or subscription behind it. Only the page or file it points to can break.

Do I need to install anything?

No. The generators run in your web browser.

Is what I type kept anywhere?

The code is built in your browser, so what you type is not uploaded. You can check this: load a generator page, switch off your internet, and make a code. It still works.
