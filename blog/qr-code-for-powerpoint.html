QR Code for a PowerPoint File

A QR code cannot carry a slide deck. It carries the address of one. Here is how to make it, why a PDF often reads better on a phone, and what we checked.

The short answer

The code holds a link, not the deck

Put the presentation somewhere with a public web address, then make a QR code of that address. Scanning the code opens the link. The file stays where you put it.

Think about the phone first

Most people who scan a code are on a phone. A PowerPoint file usually downloads rather than opening in place, and a PDF is friendlier to read. The rest of this guide covers both.

Why a PowerPoint file does not fit

We measured three decks

The largest QR code holds 2,953 bytes at the lowest error correction level. We saved three .pptx files with the Python library python-pptx and checked their sizes in bytes.

FileSize in bytesFull codes needed at the lowest level
Blank presentation27,38710
Three slides of text30,03811
Twelve slides of text37,69713

What that tells you

A .pptx file is a zipped bundle, and even a blank one is far larger than the biggest QR code can hold. Decks with images, which most real ones have, are much bigger again. The point holds either way: no presentation fits inside a code, so the code must hold a link.

How to make a QR code for a PowerPoint file

Step 1: Put the file online

Use your own website, OneDrive, Google Drive, or another service. Set sharing so that anyone with the link can open it. If a reader has to sign in or ask for access, they will see a login page instead of your slides.

Step 2: Copy the link

For a file on your own site, the link ends in .pptx or .ppt. For a cloud copy, use the share link. Our guide to QR codes for Google Drive covers Drive links in detail.

Step 3: Generate the code

Open the file and media QR code generator, paste the link and download the code. For a presentation link, the tool said: "Recognised a presentation. Presentations download rather than display. PDF is friendlier on a phone."

Step 4: Test it

Scan the code with a phone that is not signed in to your account, and open the result. Then print a test copy at its real size. See QR code size for print for the minimum width.

The .pptx file or a PDF?

When a PDF is better

If people only need to view the slides, export the deck to PDF first and link to that. A PDF opens in the phone's built in viewer, while a .pptx usually downloads. You lose the animations, but you gain a deck that opens straight away. Our PDF QR code generator covers that route.

When to link the .pptx

Link the PowerPoint file itself when people need to edit it or present from it, such as a template or a handout they will reuse. In that case, say so on the printed sign, for example "Scan to download the slides".

Code size

A 35 character .pptx link gave a 29 by 29 grid at the medium error correction level. At 0.4 mm per square plus a margin of 8 squares on each side, that needs at least 14.8 mm of width. This figure comes from calculation with a QR library, not from printing. We did not test how each phone opens a presentation, so try yours.

Mistakes to avoid

A link that needs a sign in

Share links from work or school accounts are sometimes limited to people inside the organisation. Open the link in a private window before you print anything.

A huge file over mobile data

Decks full of images can be tens of megabytes, slow to download on a weak signal. Compress the images, or link to a PDF, before you print the code.

Linking to a file you will replace

A static code cannot change. If the link points to a file on your own site, you can replace the file and keep the same address. See static vs dynamic QR codes.

Frequently asked questions

Can a QR code store a PowerPoint file?

No. The biggest code holds 2,953 bytes, and a blank .pptx we made was 27,387 bytes.

How do I turn a PowerPoint into a QR code?

Put the file online, copy its public link, and paste the link into a QR code generator.

Should I link the .pptx or a PDF?

If people only need to view it, a PDF opens faster on a phone. If they need to edit or present from it, link the .pptx.

Will the presentation download or open?

Our tool warns that presentations usually download rather than display. We did not test every phone.

Does the QR code expire?

A static code does not expire by itself. It works for as long as the file stays at that link.

Can I update the slides later?

Yes, if the link points to a file you control and you replace it at the same address. Otherwise you must make a new code.
