QR Code for an Excel File

A QR code cannot carry a spreadsheet. It carries the address of one. Here is how to make it, why a web view often beats the raw file, and what we checked.

The short answer

The code holds a link, not the workbook

Put the spreadsheet somewhere with a public web address, then make a QR code of that address. Scanning the code opens the link. The file stays where you put it.

Think about the phone first

A spreadsheet is wide, and a phone screen is narrow. If people will open your code on a phone, a published web view is usually easier to read than the raw file. The rest of this guide covers both.

Why an Excel file does not fit

We measured three spreadsheets

The largest QR code holds 2,953 bytes at the lowest error correction level. We saved three .xlsx files with the Python library openpyxl and checked their sizes in bytes.

FileSize in bytesFull codes needed at the lowest level
Blank workbook4,7832
Small sheet, 20 rows by 5 columns5,2972
Larger sheet, 500 rows by 10 columns23,2598

What that tells you

An .xlsx file is a zipped bundle, so even a blank one is larger than the biggest QR code can hold. Files saved by Excel itself, or with formatting, charts and formulas, are usually bigger than these. The point holds either way: no spreadsheet fits inside a code, so the code must hold a link.

How to make a QR code for an Excel file

Step 1: Put the file online

Use your own website, OneDrive, Google Drive, or another service. Set sharing so that anyone with the link can open it. If a reader has to sign in or ask for access, they will see a login page instead of your data.

Step 2: Copy the link

For a file on your own site, the link ends in .xlsx, .xls or .csv. For a cloud copy, use the share link. Our guide to QR codes for Google Drive covers Drive links in detail.

Step 3: Generate the code

Open the file and media QR code generator, paste the link and download the code. For a spreadsheet link, the tool said: "Recognised a spreadsheet. Spreadsheets download rather than display, and wide sheets are unreadable on a phone. A published web view is usually better."

Step 4: Test it

Scan the code with a phone that is not signed in to your account, and open the result. Then print a test copy at its real size. See QR code size for print for the minimum width.

The raw file or a web view?

When a web view is better

If people only need to read the numbers, a web view is friendlier on a phone than a file that downloads. Google Sheets can publish a sheet to the web as a page, and Excel on the web can share a read-only view. You then make the QR code from that page's link, not from the file. This also lets you update the figures without reprinting the code.

When to link the raw file

Link the .xlsx itself when people need to download it and work in it, such as a template or a form they fill in. In that case, tell people what to expect on the printed sign, for example "Scan to download the spreadsheet".

Code size

A 37 character .xlsx link and a 34 character .csv link both gave a 29 by 29 grid at the medium error correction level. At 0.4 mm per square plus a margin of 8 squares on each side, that needs at least 14.8 mm of width. These figures come from calculation with a QR library, not from printing. We did not test how each phone opens a spreadsheet, so try yours.

Mistakes to avoid

A link that needs a sign in

Share links from work or school accounts are sometimes limited to people inside the organisation. Open the link in a private window before you print anything.

A wide sheet on a small screen

A sheet with many columns is hard to read on a phone, and scrolling sideways frustrates people. Trim it to what matters, or publish a web view.

Linking to a file you will replace

A static code cannot change. If the link points to a file on your own site, you can replace the file and keep the same address. See static vs dynamic QR codes.

Frequently asked questions

Can a QR code store an Excel file?

No. The biggest code holds 2,953 bytes, and a blank .xlsx we made was 4,783 bytes.

How do I turn an Excel file into a QR code?

Put the file online, copy its public link, and paste the link into a QR code generator.

Should I link the file or a web view?

If people only need to read it, a web view is easier on a phone. If they need to download and edit it, link the file.

Will the spreadsheet download or open?

Our tool warns that spreadsheets usually download rather than display. We did not test every phone.

Does the QR code expire?

A static code does not expire by itself. It works for as long as the file stays at that link.

Can I update the numbers later?

Yes, if the link points to something you control, such as a published sheet or a file on your own site that you replace. Otherwise you must make a new code.
