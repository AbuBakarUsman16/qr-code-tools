QR Code for Office Files: Word, Excel and PowerPoint

None of these files fit inside a QR code. The code carries a link to the file. Here is the one method that works for all three, and the single difference that matters for each.

The short answer

A QR code holds text, at most 2,953 bytes of it. A Word, Excel or PowerPoint file is far larger than that, so the file cannot go inside the code. What you do instead is put the file online, then make a QR code of its web address. Scanning the code opens the link, and the phone downloads or shows the file from there.

That part is the same for all three. Where they differ is what happens after the link opens, and that is where most of the useful advice lives.

Why no Office file fits

The largest QR code holds 2,953 bytes at the lowest error correction level. We saved a blank file of each type with Python libraries (python-docx, openpyxl and python-pptx) and checked the size in bytes. Even empty, every one is too big.

Blank fileSize in bytesFull codes it would need
Excel, .xlsx4,7832
PowerPoint, .pptx27,38710
Word, .docx36,56313

These are zipped bundles, so even an empty one carries a fixed load of internal parts. Real files, with text, tables, images and charts, are larger again. No phone camera reads a dozen codes at once, so the code has to hold a link.

How to make the code, for any of them

Step 1: Put the file online

Use your own website, OneDrive, Google Drive, or another host. Set sharing so that anyone with the link can open it. If a reader has to sign in or ask for access, they see a login page instead of your file. Our guide to QR codes for Google Drive covers Drive links in detail.

Step 2: Make and test the code

Open the file and media QR code generator, paste the link and download the code. Then scan it with a phone that is not signed in to your account, and check it opens. Print a test copy at its real size first; our sizing guide has the minimum width, which for a short link is about 14.8 mm.

Everything above is identical whether the file is a document, a spreadsheet or a deck. The next three sections are the part that is not.

Word: read or edit

Most phones download a Word file rather than showing it in place. Our tool flags this and suggests exporting to PDF first. So the real question is what the reader will do:

  • Only reading it, such as a menu, a notice or a handbook. Export to PDF and link to that. A PDF opens straight away in the phone's viewer. Use our PDF generator.
  • Filling it in or editing it, such as a form or a template. Keep the .docx and label the sign "Scan to download the form", so people know it will download.

Excel: the phone screen problem

A spreadsheet is wide and a phone is narrow. Our tool warns that spreadsheets download rather than display, and that wide sheets are unreadable on a phone. The fix that most people miss is to not link the raw file at all:

  • Publish a web view. Google Sheets can publish a sheet to the web as a page, and Excel on the web can share a read-only view. Make the code from that page's link. It reads well on a phone and you can update the numbers without reprinting the code.
  • Link the .xlsx only when people genuinely need to download and work in it, such as a template.

PowerPoint: size and animations

Decks carry images, so they are often the largest of the three, tens of megabytes, slow on a weak signal. Our tool notes that presentations download rather than display, and that a PDF is friendlier on a phone.

  • Export to PDF if people only need to view the slides. It opens at once and is far smaller. You lose the animations, which is the one real trade.
  • Keep the .pptx when the animations or the editable slides are the point. Compress the images first so the download is not punishing.

What we tested

We pasted a link of each type into the live file tool and recorded the note it showed. The output always matched what we typed, and a short link of 34 to 37 characters gave a 29 by 29 grid, about 14.8 mm wide at the smallest.

Frequently asked questions

Can a QR code store a Word, Excel or PowerPoint file?

No. The biggest code holds 2,953 bytes, and even a blank Excel file we made was 4,783 bytes, a blank PowerPoint 27,387, and a blank Word document 36,563.

How do I turn an Office file into a QR code?

Put the file online, copy its public link, and paste the link into a QR code generator.

Should I link the file or a PDF?

If people only need to read a document or view slides, a PDF opens faster on a phone. For a spreadsheet, a published web view is usually better than a PDF. Link the original file when people need to edit it.

Will the file download or open?

Our tool warns that Office files usually download rather than display. We did not test every phone.

Does the QR code expire?

A static code does not expire by itself. It works for as long as the file stays at that link. See static vs dynamic QR codes.

Can I update the file later?

Yes, if the link points to something you control, such as a published sheet or a file on your own site that you replace at the same address. Otherwise you must make a new code.
