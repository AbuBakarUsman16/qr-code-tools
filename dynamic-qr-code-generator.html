Make a dynamic QR code

Static or dynamic: which one do you need?

Most codes should be static. A static code holds your link inside the picture, so it keeps working with no service behind it. All the other generators on this site make static codes.

Pick dynamic when the link will change after you print: a menu that moves to a new page each season, a flyer for an offer that ends, or a sign whose page you have not built yet. A dynamic code holds a short q.qrotto.com link, and you choose where that link sends people.

The full comparison is in our guide on static versus dynamic QR codes.

What you get, free

  • Change the link any time from your private edit link. The printed code keeps working.
  • No account. No email, no password, no trial that runs out.
  • No ads when scanned. One redirect, straight to your page.
  • Scan counts by country, device type and day, with no history limit.
  • Your own link name if you want one, such as q.qrotto.com/ali-cafe-menu.
  • Colours and a logo, with the error level raised automatically when a logo covers the middle.
  • No lock-in. Download your data, or a plain QR code that points straight to your page, from the edit page at any time.

How to make one

  1. Open q.qrotto.com and paste the https:// link the code should open.
  2. Optionally pick a link name, colours and a logo, then press Create code.
  3. Download the PNG, and save the edit link with Copy or Download. It is the only way to change the code later.
  4. Scan the printed code once yourself before handing it out. Our stress test shows how small you can print it.

How we keep it safe

Free redirect services attract scammers, and a scam on one code hurts trust in all of them. So links must use https://, short links and other QR redirects are refused, link names that imitate banks or logins are blocked, and anyone can check or report a code without opening it. A code with several reports is paused until it is checked. Adding a plus sign to any code link, like q.qrotto.com/ali-cafe-menu+, shows where it goes first.

We store the link, the edit key and scan counts. We do not store the IP address or details of anyone who scans. The rules are on the dynamic code terms page.

Questions

Is the dynamic QR code really free?

Yes. There is no paid plan and no limit on scans. You can make up to 20 new codes a day from one connection, which stops spam without getting in the way of normal use.

Do I need an account?

No. When you make a code you get a private edit link. That link lets you change where the code goes, see scans, or turn the code off. Save it, because we cannot send it to you again.

Will people see an ad when they scan?

No. A scan goes straight from q.qrotto.com to your page with a single redirect. There is no waiting page, ad or sign-up wall in between.

What happens if QRotto stops running?

A dynamic code depends on the service that redirects it, ours included. That is why every edit page has a button to download a plain QR code that points straight to your page, and why our terms promise at least 90 days of notice before any shutdown. If your link will never change, a static code is still the safer choice.

Can I choose my own link name?

Yes. Open Custom link name and pick something like q.qrotto.com/ali-cafe-menu. People see this name when they scan, so a clear name helps them trust it. Names that imitate banks, logins or big brands are blocked.
