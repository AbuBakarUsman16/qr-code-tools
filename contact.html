Reporting a code that will not scan

This is the most common thing people write in about, and the fix is usually quick once we know a few specifics. Please include:

  • Which generator you used, WiFi, vCard, URL, text, email or SMS.
  • What happens, does the camera not react at all, or does it scan and then fail to do the right thing? These have completely different causes.
  • The device and browser you generated on, and the phone you tried to scan with.
  • Whether it is printed or on screen, and roughly what size.

Before writing, it is worth checking our troubleshooting guide, it covers the causes behind most reports, including the one that catches nearly everyone: testing a WiFi code on a phone that is already connected to the network, which appears to work regardless of whether the code is correct.

Suggesting a new tool

Most of the generators on this site exist because somebody asked. If there is a QR code type you keep needing and cannot find a straightforward free version of, tell us what you would use it for. Knowing the actual situation helps far more than the feature name, the difference between "an SMS code" and "a code on each table that pre-fills the table number" changes what gets built.

What we cannot help with

To save you time:

  • Recovering a dynamic code from another provider. If a paid service stopped working, only that provider can restore it.
  • Decoding a suspicious code for you. If you think a code is malicious, do not scan it, read our QR safety guide instead.
  • Router configuration. We can explain what a WiFi code needs, but guest network setup varies by manufacturer and your router's documentation is the better source.
