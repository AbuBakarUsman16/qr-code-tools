Qrotto SEO Bar: setup

The extension adds SEO details to your Google results. Two features work right away. Domain Rating needs a free Ahrefs key, which takes about a minute.

One minute setup for Domain Rating

  1. Open your Ahrefs API keys page

    Sign in if asked. A free Ahrefs account is enough.

    Open Ahrefs API keys
  2. Generate a key

    Click Generate API key for public endpoints, give it any title such as "Qrotto", then click Generate.

  3. Copy it

    Click Copy. The key is shown only once, so copy it now.

  4. Paste it into Qrotto SEO Bar

    Click the Qrotto SEO Bar icon in your Chrome toolbar, paste the key and press Save key.

That's it. Search on Google and a DR chip appears next to each result. Your key stays in your browser and is sent only to Ahrefs, never to Qrotto.
