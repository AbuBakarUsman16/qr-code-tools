At a glance

Format written
vCard 3.0, one property per line
Fields
Full name, company, phone, email, website. All optional.
Characters escaped
\ ; ,
Error correction
Level M
Typical size
53 × 53 modules with all five fields filled

Fields

Full Name Optional

Written twice: as FN, the display name, and as N. The whole name goes into the first part of N rather than being split into first and last names.

Company / Organization Optional

Written as ORG.

Phone Number Optional

Written as TEL;TYPE=CELL, exactly as typed, spaces included. Use the full international format so it works for callers abroad.

Email Address Optional

Written as EMAIL.

Website Optional

Written as URL. Include https://.

Empty fields are left out of the code entirely.

What the code contains

All five fields

BEGIN:VCARD
VERSION:3.0
FN:Sarah Mitchell
N:Sarah Mitchell;;;;
ORG:Northgate Design
TEL;TYPE=CELL:+1 555 123 4567
EMAIL:sarah@example.com
URL:https://example.com
END:VCARD

Special characters

Backslash, semicolon and comma have a meaning in vCard, so the tool puts a backslash before each one. A name typed as Mitchell, Sarah is written as:

BEGIN:VCARD
VERSION:3.0
FN:Mitchell\, Sarah
N:Mitchell\, Sarah;;;;
END:VCARD

What it does not do

  • No photo. A photo makes the code far too dense to print on a card. How to add a photo explains the alternatives.
  • No address, job title or second phone. The five fields above are all it writes.
  • Empty form. Pressing Generate with every field empty still makes a code, holding a contact with no details:
BEGIN:VCARD
VERSION:3.0
END:VCARD

On a business card, a link to a contact page is often the better choice; see QR code for a business card.
