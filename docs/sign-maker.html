Fields

FieldUse
Where the code should goThe link or text in the code
HeadingLarge text above the code, such as Scan for the menu
Line under the codeOptional, such as Point your camera at the code. Not printed on the sticker format.
Business nameOptional, centred along the bottom. Not printed on the sticker format.
Ink and paper colourAny colours. Keep the ink much darker than the paper.

Check and downloads

The sign maker decodes the finished sign. When it reads, it tells you the code's width and reading distance; when it does not, it says to shorten the link or raise the contrast between ink and paper.

  • PDF at the paper size of the format.
  • PNG at 300 dpi.

Print at 100%Choose actual size or 100% in the print dialog, not fit to page. Scaling changes the code size the format was chosen for.
