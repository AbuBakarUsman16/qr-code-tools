At a glance

Modes
Booking page, Text message, WhatsApp, Phone call
Number cleaning
Everything but digits is removed, then + is added, so include the country code
Error correction
Level M

The four modes

ModeFields usedWhat the scanner sees
Booking pageYour booking pageOpens your booking page.
Text messageYour number, how many people, the messageOpens a text message to you with the request typed. They still press send.
WhatsAppYour number, how many people, the messageOpens a WhatsApp chat with the request typed. They still press send.
Phone callYour numberOpens the dialler with your number filled in. The caller still presses call.

What the code contains

Booking page, typed as example.com/book

https://example.com/book

Text message, restaurant, party of 2

SMSTO:+12125550123:Hi, I would like to book a table for 2.

WhatsApp, salon

https://wa.me/12125550123?text=Hi%2C%20I%20would%20like%20to%20book%20an%20appointment.

Phone call, typed as +1 (212) 555-0123

tel:+12125550123

Preset messages

For text and WhatsApp, the message is filled in for the kind of place you pick, and you can edit it. How many people starts at 2; choose Do not mention a number to leave it out.

Kind of placePreset message
Restaurant or cafeHi, I would like to book a table for {n}. With no party size, the for {n} part is left out.
Salon or barberHi, I would like to book an appointment.
Clinic or practiceHi, I would like to book an appointment.
Rooms, studio or venue hireHi, I would like to enquire about booking the space.
Something elseHi, I would like to make a booking.

What it does not do

  • It takes no bookings itself and keeps no calendar. It only opens a way to contact you.
  • Texts and WhatsApp messages are not sent until the person presses send.
