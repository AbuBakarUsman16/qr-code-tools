Email QR code

At a glance

Format written
mailto: link, with subject and body when filled
Encoding
Subject and message are percent encoded, so spaces become %20
Error correction
Level M

Fields

Email Address Required

Where the email goes. With this empty, Generate does nothing.

Subject Optional

Pre-fills the subject line.

Message Optional

Pre-fills the body. The person can edit it before sending.

What the code contains

Address only

mailto:hello@example.com

With subject Table booking and message Hi, a table for 2 & a high chair?

mailto:hello@example.com?subject=Table%20booking&body=Hi%2C%20a%20table%20for%202%20%26%20a%20high%20chair%3F

Commas, ampersands and question marks in the message are encoded too, so they cannot break the link.

What it does not do

  • It does not send anything. The phone's mail app opens, and the person decides whether to send.
  • It cannot add CC, BCC or attachments.
  • On a phone with no mail app set up, the code may do nothing useful.
