The scan check

After every change the designer decodes the exact image it drew and compares it with what you entered.

  • Scans correctly means the decoded text matched.
  • Does not scan means it did not. Reduce the logo, raise the contrast or use square modules.

Even when it scans, it warns you when:

  • contrast between code and background is below 4 to 1, measured on the lighter end of a gradient;
  • the logo covers more than 15% of the code;
  • the code is lighter than its background, which many scanners refuse;
  • the background is transparent, since it takes the colour of whatever it is printed on.

The check is a clean digital image. Print a copy and scan it with a phone before printing many.

Downloads

  • PNG includes everything, logo and text.
  • SVG is rebuilt from your settings so it stays sharp at any size. A logo is not included in the SVG, because a logo is a picture rather than a shape.

The designer does not export PDF. For a print ready PDF, use the Sign maker.
