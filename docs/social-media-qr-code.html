What the code contains

Instagram, typed as @qrotto

https://instagram.com/qrotto

LinkedIn, typed as jane doe

https://linkedin.com/in/janedoe

Discord invite code

https://discord.gg/AbC12

LinkedIn and some other platforms use a profile address that differs from your display name. Copy it from your profile page rather than typing your name.

What it does not do

  • It does not check that the profile exists.
  • One platform per code. For several, link to one page that lists them all; see One QR code for all social media.
