At a glance

Format written
SMSTO:<number>:<message>
Number cleaning
Spaces are removed. Brackets and dashes are kept.
Error correction
Level M

Fields

Phone Number Required

Your number in international format, starting with + and the country code. Type it as digits: spaces are removed, but brackets and dashes would stay in the code.

Prefilled Message Optional

Text that appears in the message box, written as typed. A keyword such as BOOK at the start makes replies easy to sort.

What the code contains

Number +1 555 123 4567 with a message

SMSTO:+15551234567:BOOK table for 2

Number only

SMSTO:+15551234567:

What it does not do

  • It does not send the text. The person's messaging app opens and they press send.
  • It has no WhatsApp option. The Booking generator can make a WhatsApp code.
  • Standard message rates apply to the person sending.
