At a glance

Format written
SMSTO:<number>:<message>
Number cleaning
Spaces are removed. Brackets and dashes are kept.
Error correction
Level M

Fields

Phone Number Required

Your number in international format, starting with + and the country code. Type it as digits: spaces are removed, but brackets and dashes would stay in the code.

Prefilled Message Optional

Text that appears in the message box, written as typed. A keyword such as BOOK at the start makes replies easy to sort.

What the code contains

Number +1 555 123 4567 with a message

SMSTO:+15551234567:BOOK table for 2

Number only

SMSTO:+15551234567:

What it does not do

  • It does not send the text. The person's messaging app opens and they press send.
  • It has no WhatsApp option. The Booking generator can make a WhatsApp code.
  • Standard message rates apply to the person sending.

Message length and size

The number and the message both go inside the code, so every character you add makes the grid bigger. We made two codes with the same number:

MessageGridSmallest print width
BOOK table for 2 (16 characters)29 × 2920 mm (0.8 in)
160 characters, one full text message53 × 5324.4 mm (1 in)

A short keyword is enough. The person can type the rest themselves, and a small code scans faster from a poster or a table card.

Common mistakes

Typing the number with brackets and dashes

Spaces are removed, but brackets and dashes stay. Typed as +1 (555) 123-4567, the code contains:

SMSTO:+1(555)123-4567:Hi

Most phones cope, but some messaging apps treat the brackets as part of the number. Type digits only, starting with + and the country code.

Leaving out the country code

A local number only works for people in your country. Tourists and anyone on a foreign SIM will text the wrong place. Always start with + and the country code.

Worrying about colons in the message

The format uses a colon to split the number from the message, so people expect a colon in the text to break it. It does not: everything after the second colon is the message.

Message BOOK: 2 people, 7:30pm

SMSTO:+15551234567:BOOK: 2 people, 7:30pm

We scanned this with jsQR and the whole message came back as typed.

Questions

Does the SMS code send the text by itself?

No. Scanning opens the messaging app with the number and message filled in. Nothing is sent until the person presses send, and the normal message rate applies to them.

Can I change the number after printing?

No. The number is written into the code itself. If the number may change, put a link to a page with your contact details in the code instead, using the URL generator.

Does it work on both iPhone and Android?

SMSTO is the common format for text message codes, but camera apps differ. Test one printed copy on the phones your customers use before you print a batch.
