Length and size

Every character adds to the grid. A short note fits a simple code; a long paragraph makes a very dense one that needs printing much larger. Watch the badge under the code, and see our text QR code guide for measured sizes.

What it does not do

  • Text in a code is not a link. Phones show it; most will not act on it.
  • It has no formatting: no bold, no colours, no images.
  • Text cannot be changed after printing. For anything that may change, link to a page instead.
