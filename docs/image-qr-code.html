Image QR code

A QR code cannot hold a picture. This tool puts the address of an image into a code and warns when the address looks like a page rather than the picture itself.

Common mistakes

Linking to a gallery page instead of the picture

A page that shows the picture is fine to link to, but it loads slowly and may show adverts or a cookie banner first. A direct link ending in .jpg or .png opens the picture on its own.

A private Drive or cloud link

If the picture is only shared with you, everyone else sees a sign in page. Set the file to anyone with the link, then open the link in a private browser window to check. The Google Drive generator also rewrites the link so the picture previews properly.

Deleting or moving the picture later

The code only holds the address. Rename, move or delete the file and every printed code breaks. Keep the picture at the same address for as long as the code is in use.

Questions

Can a QR code show a picture without the internet?

No. The largest code holds 2,331 bytes at level M, far less than even a small photo. The phone needs a connection to load the picture from its link.

Where should I host the picture?

Your own website, or any service that gives a public link that does not change. Avoid links that expire, such as some file transfer services.

How do I check the link before printing?

Open it on your phone with WiFi off, using mobile data. If the picture appears on its own, the code will work for others too.
