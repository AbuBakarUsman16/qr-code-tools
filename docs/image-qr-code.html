Image QR code

A QR code cannot hold a picture. This tool puts the address of an image into a code and warns when the address looks like a page rather than the picture itself.

At a glance

Format written
The link, with https:// added if missing
Picture formats recognised
jpg, jpeg, png, gif, webp, avif, svg, bmp, tif, tiff
Updates
As you type
Error correction
Level M

What the code contains

A direct link to a picture

https://example.com/poster.jpg

The notes it shows

When the linkThe tool says
ends in a picture extensionHow many characters it is, and to open it in a fresh tab and check you see the picture on its own.
does notThis does not end in an image file extension, so it is probably a page showing the image rather than the image itself. Right click the picture and copy image address instead.
is a Google Drive linkThat our Drive generator rewrites it so the image previews properly.
is over 90 charactersThat it is long and makes a dense code that needs printing larger.

What it does not do

  • It does not host your image.
  • It cannot put the picture itself into the code; even a small photo is many times what the largest code holds.
