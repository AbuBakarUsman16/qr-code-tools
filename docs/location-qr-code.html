At a glance

Modes
An address, or GPS coordinates
Formats
Google Maps link, or geo: for coordinates
Error correction
Level M

Fields

Address Address mode

Any address or place name. It is encoded into a Google Maps search link.

Latitude and Longitude Coordinates mode

Decimal degrees, such as 53.959965 and -1.087298. Both are needed. They are written as typed.

Format Coordinates mode

Maps link (works everywhere) or geo: code (works offline). Address mode always makes a Maps link.

What the code contains

Address

https://maps.google.com/?q=Village%20Hall%2C%20Main%20Street%2C%20York

Coordinates as a Maps link

https://maps.google.com/?q=53.959965,-1.087298

Coordinates as a geo: code

geo:53.959965,-1.087298

Maps link or geo:

A geo: code is shorter and does not go through a website: the phone hands it straight to its default map app. Support is good on Android and less consistent on iPhone. The Google Maps link works on any phone with a browser, so it is the safer choice when you cannot predict who will scan. Our location format test compares them.

Common mistakes

Commas instead of decimal points

Maps need a dot for decimals: a comma makes four numbers out of two, and the pin lands in the wrong place. Many countries write 53,959965, so the tool turns a decimal comma into a dot. Typed that way, the code contains:

https://maps.google.com/?q=53.959965,-1.087298

Numbers outside the possible range, such as a latitude over 90, are refused with a message.

Latitude and longitude the wrong way round

Latitude comes first. Swapped, our York test point became geo:-1.087298,53.959965, a point in the Indian Ocean. Google Maps shows latitude first when you click a point, so copy from there.

An address that matches several places

Address mode makes a Google Maps search, so a short address such as Main Street can match many towns. Include the town and postcode, or use coordinates for a field, car park or back entrance with no clear address.

Questions

Does a location code work offline?

A geo: code is handed straight to the map app, so it can open offline if the app has offline maps. The Google Maps link needs a connection to load.

Can it start turn by turn directions?

It opens the map at your place. The person taps Directions from there.

How big should I print it?

Our address code made a 37 × 37 grid (20 mm (0.8 in)). The geo: code was 25 × 25 (20 mm (0.8 in)), the smallest of the three.
