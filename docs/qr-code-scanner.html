At a glance

Inputs
An image file, a dragged image, a pasted image, or the camera
Decoder
jsQR 1.4.0, run in your browser
Light on dark codes
Read as well as dark on light
Upload
None. Images and video stay on your device.

Three ways in

  • Choose an image picks a photo or screenshot from your device.
  • Drag or paste: drop an image onto the page, or copy one and paste it with Ctrl+V or Cmd+V.
  • Use camera reads from your webcam or phone camera until it finds a code. Stop camera ends it.

What it reports

It names the kind of code and prints the full contents as plain text, so you can read a link before you open it.

It recognisesFrom contents starting with or shaped like
Website linkhttp:// or https://
WiFi networkWIFI:
Contact cardBEGIN:VCARD
Calendar eventBEGIN:VEVENT
Emailmailto:
Phone numbertel:
Text messageSMSTO:
Locationgeo:
Plain textAnything else

For a website link, an email or a phone number it also offers an Open this link button. Codes in other formats, such as a calendar file starting BEGIN:VCALENDAR, are shown as plain text, with the full contents still visible.

Messages

WhenIt says
No code in the imageNo code detected in that image. Try a tighter crop around the code.
Camera running, nothing found yetStill looking. Hold the code steady and fill more of the frame.
Camera permission refusedCamera access was refused. Upload a photo of the code instead.
Browser has no camera supportThis browser cannot open the camera. Upload a photo of the code instead.

If a picture will not read, Scan a QR code from an image lists fixes we measured.

Privacy

Images and camera video are decoded on your device and are not uploaded. Once the page has loaded, scanning a saved image works with the connection off.
