Static codes and privacy

Every code made here is static: what you typed is written into the code itself. That decides how long it lasts and who can read it.

What static means

A static code holds your link, text or details directly. A dynamic code holds a short address on someone else's server, which then forwards the phone to your real destination. QRotto only makes static codes.

Static: the code contains your address

https://example.com/menu

A dynamic code would contain something like a short link on the provider's domain instead, and only that provider knows where it leads.

Why the codes do not expire

There is nothing on our side for a static code to depend on. If QRotto disappeared tomorrow, every code made here would keep working, because the phone reads the destination straight from the printed pattern. A code only stops working if what it points to stops working, such as a page you delete.

Changing a code later

You cannot change a static code after printing. To keep the option, point the code at an address you control, such as a page on your own website, and change what that page shows. Our guide to static and dynamic codes goes further.

What we collect

What you type into a generator is not uploaded. Codes are drawn on your device, and the text you enter is not sent to our analytics.

The site does use Google Analytics, Microsoft Clarity and Google AdSense, which set cookies and see which pages are visited. Clarity masks the text typed into fields. The privacy policy lists each service.

What a scanner can read

Anything in a code is readable by anyone who scans it or photographs it. A WiFi password, a phone number or a home address in a code is effectively published. Use a guest network for WiFi codes on display, and a business number rather than a personal one.
