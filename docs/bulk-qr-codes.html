The list format

  • Each line is encoded exactly as written, after trimming spaces at the ends. Empty lines are skipped.
  • To name a code, start the line with a label of up to 60 characters and a vertical bar. The label names the file and is printed under the code on the PDF sheet; it is not part of the code.
  • Lines without a label are named code-1, code-2 and so on, by position.

Downloads

  • PNG zip: one image per code, named from its label. Repeated labels get -2, -3 added.
  • SVG zip: the same as vector files, for printers and design software.
  • PDF sheet: A4 pages with 12 codes each in 3 columns, every code 48 mm (1.9 in) wide with its label under it. Labels longer than 26 characters are cut short on the sheet.

Limits

  • More than 250 lines: That is 251 codes. The limit is 250 per batch, split the list.
  • No lines: Add at least one line first.
  • A line too long for any QR code is skipped and counted in the status message.
  • The bulk tool makes plain codes. For colours or a logo, use the Designer one code at a time.
