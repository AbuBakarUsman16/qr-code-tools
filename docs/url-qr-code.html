Fields

Website URL Required

The full address, starting with https://. Spaces at the start and end are removed. Nothing else is changed.

What the code contains

A full address

https://example.com/menu

An address typed without https://

example.com/menu

Type the https:// yourselfThis generator writes the address as typed. Without https://, some phone cameras treat it as plain text and offer a search instead of opening the page. The PDF, Image and File generators add it for you; this one does not.

What it does not do

  • It does not check that the page exists or loads on a phone.
  • It does not shorten long links. Long links make denser codes; see Print size and the scan badge.
  • It does not track scans. Add your own analytics tags to the address if you need them.

Troubleshooting

The phone shows text instead of opening the page

Add https:// to the start of the address and make the code again.

The page opens but shows an error

The code holds exactly what you typed, so the address itself is wrong or the page needs a sign in. Open the address in a private browser window to see what a stranger sees.
