Three words worth knowing

They explain almost every reason a code fails to scan.

ModuleOne square of the code. Smaller modules are harder for cameras to see. Quiet zoneThe white border around the code. Cropping it is the most common print mistake. Error correctionSpare data that lets a code scan even when part of it is damaged or covered.
