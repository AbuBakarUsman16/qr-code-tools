The link you copied is usually the wrong one

Put a Google Docs link straight into a QR code and it will almost certainly end in /edit. That address asks the phone to open the full editor, which on a small screen means a slow load, a sign in prompt for anyone not already logged in, and a document that can be changed by accident.

Drive has other addresses for the same file. This tool pulls the file id out of whatever you paste and rebuilds the link in the form that suits what you actually want to happen.

What each option does

OptionWhat the scanner getsGood for
PreviewA clean read only view, no editing toolbarMenus, handouts, price lists, anything public
DownloadThe file itself, straight to their deviceForms to fill in, files people keep
Open as normalThe standard Drive or editor viewColleagues who are meant to edit it

Preview is the right default for anything printed and pointed at the public. It is the fastest to load, it does not invite editing, and it does not look like a workspace.

The sharing setting that decides everything

No link format can get round permissions. If the file is set to Restricted, every one of these addresses will show a request access screen to anyone outside your organisation, and your printed sign will be useless.

In Drive, open Share, then under General access change Restricted to Anyone with the link, and set the role to Viewer. Viewer matters: with Editor, anyone who scans your poster can change the document.

Test it the way a stranger would. Open a private browsing window, sign out of Google, and paste the link. If you see the document, your sign will work. If you see a request access page, the sharing setting is still wrong, not the QR code.

The code does not hold the file

Worth being plain about, because plenty of tools imply otherwise. A QR code holds at most 2,331 bytes at the common error correction level. A one page PDF is around 25 KB, which is about twelve times over that limit, and a short video is over a thousand times over it.

So a QR code for a Drive file is, and can only be, a link. That has one consequence worth planning for: the code works for exactly as long as the file stays in that Drive at that address. Move it, delete it, or leave the account, and every printed copy breaks. For anything going to print in quantity, point the code at a short address on a domain you own and redirect from there, so you can move the file later without reprinting.

Common questions

Does this work with Google Sheets and Slides?

Yes. Paste any Docs, Sheets, Slides or Drive file link and the tool recognises which it is and offers the right preview address for that type.

Will the person need a Google account?

Not if the file is shared with Anyone with the link. If it is restricted, they will be asked to sign in and then to request access, which is where most of these codes fail.

Can I make the file download instead of opening?

Yes, choose the download option. It uses Drive's direct download address. Note that very large files show a virus scan warning page first, which Drive adds and no link format avoids.

Is my link sent anywhere?

No. The rewriting and the code are both done in your browser. Nothing about your file or your link leaves this page.

Why is my code quite dense?

Drive file ids are long, so these links run to about 60 or 70 characters and the code is busier than a short URL. That matters for small printed sizes. Our sign size guide has the character budget for each print size, and the stress test will tell you how much blur yours survives.
