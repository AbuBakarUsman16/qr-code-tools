What Can You Encode?

This tool accepts any plain text — a short note, a physical address, an event detail, a product code, or instructions. Unlike a URL QR code, scanning it simply displays the text rather than opening a link.

Tips for Reliable Scanning

Keep the text reasonably short for a cleaner, easier-to-scan code — very long text creates a denser QR pattern that can be harder for some cameras to read at a distance. When printing, leave white space around the code and avoid shrinking it below about 2cm per side.
