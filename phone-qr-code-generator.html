What a phone QR code does

A phone QR code holds a tel: link. Scanning it opens the dialler with your number already entered, so the caller taps once instead of copying digits off a sign and retyping them.

It sounds small, but transcription is where enquiries get lost. A number read off a van at a junction, or off a shop window in the rain, gets remembered wrong more often than people admit.

Getting the number format right

Write the number in full international format, starting with the country code. Our generator strips spaces, brackets and dashes automatically, but the country code is yours to get right:

Notice the pattern outside the US: the leading zero is dropped and replaced by the country code. Keeping the zero is the single most common reason a scanned number fails to connect for an international caller.

A local number still works locally without the country code. But a code on a shop window will eventually be scanned by a visitor whose phone is registered abroad, and for them the international form is the only one that dials.

Where a phone code earns its place

  • Vans and vehicle livery. Nobody writes down a number from a moving vehicle, but they will scan one at a red light.
  • Shop windows and A boards. Works after closing time, when the alternative is walking away.
  • Estate agent boards. A passer by can call about the property from the pavement.
  • Equipment and service labels. Whoever finds the fault can call the right number without hunting for it.
  • Emergency contact cards. Works with no internet at all, which matters in exactly those situations.

Phone codes suit urgency. If the enquiry can wait, an SMS or email code gets a better response rate, because calling a stranger is a bigger ask than sending a message.

Common questions

Does it dial automatically?

No, and it should not. The dialler opens with the number filled in and waits for the user to press call. Both iOS and Android build that safeguard into the operating system rather than leaving it to the code.

Can I add an extension?

Some phones handle a comma or a p as a pause before extension digits, but support is inconsistent. For anything that must work reliably, put the main number in the code and the extension as printed text beside it.

Will it work on a tablet or laptop?

Devices without a phone app usually offer to call through an app such as FaceTime or Skype, or do nothing. The code is aimed at phones.

Is my number private?

No. A printed phone code publishes the number to anyone who scans it, and it is readable in the code contents even without dialling. Use a business line for anything public.

Printing it so it works

Phone codes hold very little data, which makes them one of the sparsest and most forgiving code types. That gives you room to print small, but the usual rules still apply: at least 2cm per side, dark on light, and a clear white margin. Why call rates beat message rates, and when they do not

A phone code asks more of the person scanning than a message code does. Dialling a stranger is a bigger commitment than typing a text, and that shows up in who responds.

The trade is worth making when the enquiry is urgent or high value: a locksmith, an emergency plumber, a property viewing. Someone standing outside a locked door will call. The same person browsing at home would rather send a message and get on with their evening.

A practical approach for signage is to print both, a phone code for now and an SMS code for later, each clearly labelled. Two small codes with one word of explanation each convert better than one unlabelled code that might do either.

Labelling the code

An unlabelled QR code on a sign gets very few scans, because nobody scans a code without knowing what it does. Three words fix it:

  • "Scan to call" is clearer than a bare code and sets the expectation correctly.
  • Print the number as text too. Some people will prefer to dial it, some phones will not cooperate, and the cost is one line.
  • Add your opening hours if calls outside them go unanswered. A missed call is worse than no call, because the person assumes you are unreliable rather than closed.
